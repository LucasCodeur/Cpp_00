# CPP Module 00

## Overview

**CPP Module 00** is the first module of the **42 C++ curriculum**. It introduces the fundamentals of object-oriented programming and the transition from C to C++.

The module focuses on classes, member functions, standard input/output, and basic object-oriented design.

## Objectives

* Discover the C++ language and its syntax.
* Create and manipulate classes.
* Implement constructors and member functions.
* Work with private and public members.
* Use standard input and output streams.
* Understand basic object-oriented programming concepts.

## Skills Developed

* **C++**
* Classes and objects
* Encapsulation
* Member functions
* Constructors
* Access specifiers
* Standard streams
* Object-oriented programming

## What I Learned

This module introduced me to the fundamental concepts of C++ and object-oriented programming, while highlighting the differences between procedural programming in C and object-oriented programming in C++.
